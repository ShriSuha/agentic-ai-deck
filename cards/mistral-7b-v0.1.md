# Mistral-7B-v0.1

## What it does

`Mistral-7B-v0.1` generates text. It is a 7-billion-parameter base model. People prompt it to draft, explain, or continue writing. Version 0.1 is the base model, not the later instruction-tuned chat model.

## License

Apache License 2.0.

## Training data

The publisher has not released the full training mix. Public descriptions say it was trained on a large web-and-book style corpus.

## Limits

- Because the training mix is not fully public, you cannot audit every source.
- It can invent citations and facts.
- It is not trained to answer only from a folder of files.
- It does not take images as input in this base release.

# m2m100-418M

## What it does

`m2m100-418M` translates written text between many languages. Unlike a single English-to-German model, it can translate directly from one of about 100 languages into another without going through English first.

## License

MIT License.

## Training data

Mined parallel sentences covering many language pairs, built for the M2M-100 project.

## Limits

- Quality is uneven. High-resource languages such as French work better than low-resource ones.
- It translates text. It does not classify images or transcribe speech.
- The 418M size is the smaller M2M-100 model, so it is less accurate than the larger ones.
- It can produce fluent text that is still a wrong translation.
